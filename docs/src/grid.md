# Grids

`Grid` objects are used to describe the physical dimension and discretization of physical space.

Examples are given in [Constructors](@ref grid.constructors). They are used to construct a distributed [`Field`](@ref).

!!! info
    Only 2D and 3D rectilinear grids are supported at the moment.
